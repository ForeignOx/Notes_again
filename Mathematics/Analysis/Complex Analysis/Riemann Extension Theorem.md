## Theorem
If [[Complex Functions|$f$]] is [[Holomorphicity|holomorphic]] and [[Boundedness|bounded]] on some punctured ball $B_{R}^{*}(a)$, for some $R>0$, then 
### Proof
If $\left| f(z) \right|\leq M$ for some $M>0$, when $z\in B_{R}^{*}(a)$, then
$$
0\leq \left| (z-a)f(z) \right| \leq M\left| z-a \right| \to 0\text{ as }z\to a
$$
$$
\implies\lim_{ z \to a } (z-a)f(z)=0
$$
So singularity is removable, so $f$ extends to a holomorphic functrion at $z=a$ by the lemma
## Corollary
Suppose $f:D\to \mathbb{C}$ is holomorphic on $D\setminus S$ where $S$ is a discrete set on which $f$ is continuous. Then $f$ is actually holomorphic on $D$
