## Definition
For a closed [[spacecurves|spacecurve]] $\underline{x}(s)$, a constant conformal measure $\mathcal{M}(\underline{x})$ is one which is unchanged by the following transformations:
- Translations, $\mathcal{M}(\underline{x}+\underline{a})=\mathcal{M}(\underline{x})$ for $\underline{a}\in \mathbb{R}^{3}$
- Rotations, $\mathcal{M}(\mathcal{R}(\underline{x}))=\mathcal{M}(\underline{x})$ if $\mathcal{R}$ is some real valued rotation matrix
- Length dilation applied equally along all three axe, $\mathcal{M}(c\underline{x})=\mathcal{M}(\underline{x})$ for $c\in \mathbb{R}$, $c\neq 0$
- Any combination of the above
In esence constant conformal invariance states that any constant conformal invariant $\mathcal{M}$ will be unchanged, a long as the global geometrical inter-relationships of $\underline{x}$ remain the same
